## Current status

Provd is still under active development. Public API access is not open yet, and the platform is not currently available for general beta testing or production use.

The current website and documentation outline the intended product direction, integration model, and system design so partners and early supporters can understand where the platform is heading.

## What is being built

The Provd API is being designed as a fraud-intelligence layer for African P2P crypto, stablecoin, and OTC workflows. The intended surface area includes:

- Counterparty risk scoring before release
- Risk flags and decision support for operator workflows
- Dispute and outcome intelligence
- Audit-oriented response data for review teams

## What to expect before beta

Before beta access opens, the public site will focus on:

- Product direction
- Technical documentation and integration intent
- Policy and legal documentation
- Architecture and workflow communication

This means some API details may continue to evolve while the platform is still being built.

## Beta notifications

Once Provd is ready for beta testing and early usage, updates will be shared through the project communications channel.

That channel will be used to announce:

- beta availability
- onboarding timing
- access criteria
- implementation updates
