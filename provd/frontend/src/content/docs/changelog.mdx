## 2026-10-03

- Provd now scores money movement on African rails before funds are released. First coverage: USDT on Tron, with M-Pesa and bank rails as fiat context.
- New API under `/v1`: `POST /v1/actions/evaluate`, `GET /v1/decisions/{intent_id}`, `POST /v1/outcomes`, `GET /v1/counterparties/tron/{address}`, `GET /v1/usage`, `GET /v1/pricing`, `POST /v1/topups`, `GET /v1/topups`.
- Pay as you go: 100 free checks a day, then prepaid bundles topped up with USDT (TRC-20) or M-Pesa.
- Public [counterparty check](/check) on the website.
- Earlier APIs under `/api/v1` and their documentation have been retired.
