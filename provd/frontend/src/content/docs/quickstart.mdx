## Overview

Integrate Provd by calling the scoring endpoint **before** releasing crypto or fiat. You’ll receive:

- A trust score
- A risk level
- A list of flags
- Suggested actions for your flow

## Minimal request

```bash
POST /v1/trust/score
```
