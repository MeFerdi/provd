## Public endpoints

Reading ratings (`GET /protocols`, `GET /protocols/{slug}`), scanning a contract (`POST /scan`) and requesting early access (`POST /early-access`) need no authentication.

Public endpoints are rate-limited per client. When you exceed the limit the API responds with `429 Too Many Requests`; wait and retry with backoff.

## API keys

Watchlists, webhooks and higher limits are part of the Pro and Protocol plans, currently in early access. Keys are issued to design partners directly. [Request early access](/early-access) and tell us what you want to monitor.

## Good practice

- Treat scan results as a point-in-time read. Use the `checked_at` timestamp when you store them.
- Cache `GET /protocols` responses; ratings are regenerated periodically, not on every request.
- Never put an API key in client-side code once you have one.
